VeritasAI — Judges & System Architecture Brief

Everything evaluators need to know about the prediction pipeline, Groq LLM synthesis, web evidence & tech stack.

Executive Summary

Multi-Signal Fake News Verification for India & the World

VeritasAI goes beyond standard single-model text classifiers. Traditional NLP models fail because modern misinformation is crafted with deceptive, high-credibility tone. VeritasAI combines Dual-Model Machine Learning, Real-Time 3-Pass Web Verification, Authoritative Fact-Check APIs, and Groq Llama-3.3-70B Neural Reasoning to answer the ultimate media question: "Is this claim verified by ground-truth evidence?"

Why Naive ML Classifiers Fail

Pure stylistic models (TF-IDF/BERT trained on article text alone) suffer from label-leakage and easily fall for polished propaganda written in neutral journalistic prose. They also hallucinate confidence on unverified Breaking News.

The VeritasAI Multi-Signal Solution

By decoupling Statement Credibility (LIAR Benchmark) from Stylistics, searching 13 Indian news hubs + direct RSS, and using The Uncertain Logic Gate, VeritasAI guarantees zero false-confidence guesses.

The 5 Intelligence Layers
Layer Component Function & Implementation Details
Layer 1 Model A — Stylistic ML TF-IDF (5,000 n-grams) + Logistic Regression on 6,300+ news texts. Evaluates surface writing structure (92.3% accuracy).
Layer 2 Model B — LIAR Classifier Evaluates headline & claim credibility against 12.8k labeled political statements from PolitiFact/LIAR dataset.
Layer 3 3-Pass Web & RSS Engine Searches 13 Indian publishers via NewsAPI + live XML RSS scrape of NDTV, The Hindu, HT, IE, ToI, Print, Scroll.
Layer 4 Google Fact Check API Cross-references AltNews, BOOM Live, PolitiFact, FactCheck.org, Vishvas News, and Newschecker.
Layer 5 Groq Llama-3.3-70B LLM Synthesizes all 4 signals + world knowledge, enforces Uncertain Logic Gate and Scare-Word Neutralization.

Multi-Aspect Ensemble ML Engine & Anti-Bias Protection

How VeritasAI combines independent models while preventing artificial keyword cheating during training and inference.

Model A — Stylistic Classifier

  • Dataset: 6,300+ labeled full news articles
  • Algorithm: TF-IDF Vectorizer (5,000 max n-grams) + Logistic Regression
  • Accuracy: 92.3% | F1 Score: 92.0%
  • Focus: Evaluates article surface writing structure, vocabulary, and clickbait syntax.

Model B — LIAR Claim Classifier

  • Dataset: PolitiFact / LIAR Benchmark (12.8k political statements)
  • Algorithm: Linear Classifier with legacy scikit-learn unpickling wrapper
  • Focus: Evaluates headline & claim credibility based on historical statement truthfulness patterns.
  • Priority: Carries 90% weight in the combined baseline ML score.
Ensemble Score Formula
Score_real = (0.90 × TruthProb_ModelB) + (0.10 × Probs_ModelA[REAL])

If Score_real ≥ 0.5, Baseline ML outputs REAL; otherwise FAKE.

Label-Leakage Guardrail (src/preprocess.py)
META_BLOCKLIST Strip Engine

Many news datasets contain words like "fake", "hoax", "debunked", or "misinformation" inside the raw text. If an ML model trains on these, it learns to cheat rather than analyze true journalistic patterns. VeritasAI uses a compiled regex guardrail to strip all label leakage terms at both training and inference time:

META_BLOCKLIST = {
    "fake", "real", "hoax", "satire", "debunked", "misinformation",
    "misleading", "conspiracy", "unverified", "disproven", "fabricated"
}
_BLOCKLIST_PATTERN = re.compile(r'\b(' + '|'.join(META_BLOCKLIST) + r')\b', re.IGNORECASE)

Groq Llama-3.3-70B Synthesis Engine & Guardrails

How the neural reasoning layer synthesizes ML confidence, live web coverage, and 70-billion parameter world knowledge to produce cited explanations.

🛡️ Guardrail 1: The Uncertain Logic Gate

If an input claim lacks cross-referenceable evidence on fact-check databases or Tier 1/2 news portals, and cannot be logically verified by 70B world knowledge, the system outputs UNCERTAIN / Unverified instead of making a false-confidence guess. Honesty over blind prediction.

🛡️ Guardrail 2: Scare-Word Neutralization

Sensational keywords like radiation, bioweapon, chemtrails, nano-chips, or secret clause are prohibited from automatically triggering FAKE verdicts without verified fact-check proof. This eliminates false-positive alarms on legitimate scientific reporting.

Offline Fallback Engine (src/reasoner.py)

If the Groq API key is unconfigured, rate-limited, or encounters network failure, the application instantly fails over to src/reasoner.py—a local rules-based resolution engine that guarantees zero UI downtime.
